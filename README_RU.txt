КВАНТОРИУМ — ОБНОВЛЁННЫЙ ПРОТОТИП ЗАПИСИ
==========================================

ЧТО ИЗМЕНЕНО
- Дизайн оформлен в цветах логотипа: тёмно-синий, голубой, красный, оранжевый и зелёный.
- Логотип добавлен в шапку сайта.
- Добавлен блок направлений с короткими рекламными описаниями в стиле примера поста.
- Время работы на сайте указано: понедельник–пятница, 10:45–18:25; суббота и воскресенье — выходные.
- В форме для выбора дней оставлены только понедельник–пятница, а время начала ограничено 10:45–18:25.
- В форме есть обязательные поля «Фамилия» и «Имя».
- Публичная страница аналитики и публичный API аналитики удалены.
- Сервер анализирует заявки в фоне и отправляет письмо ответственному сотруднику, когда
  набирается MIN_GROUP_SIZE заявок с одинаковым направлением и днём, а время отличается
  от первого участника группы не больше чем на TIME_TOLERANCE_MINUTES.
- Добавлена ссылка на официальные образовательные программы Кванториума.

ЗАПУСК
1. Установить Node.js версии 20 или новее: https://nodejs.org/
2. Распаковать архив.
3. Открыть папку Kvantorium в Visual Studio Code.
4. Выбрать «Терминал → Создать терминал».
5. Выполнить: npm install
6. Запустить: npm start
7. Открыть: http://localhost:3000

Если PowerShell блокирует npm.ps1, в текущем терминале можно выполнить:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
Затем повторить npm install.

БАЗА ДАННЫХ
При первом запуске автоматически создаётся data/kvantorium.sqlite.
Не удаляйте этот файл, если нужно сохранить заявки.

НАСТРОЙКА EMAIL
1. Скопируйте .env.example в файл .env в корне проекта.
2. Заполните параметры SMTP и адрес получателя:
   SMTP_HOST=адрес SMTP-сервера
   SMTP_PORT=587
   SMTP_SECURE=false
   SMTP_USER=логин почты
   SMTP_PASS=пароль приложения или SMTP-пароль
   MAIL_FROM=адрес отправителя
   MAIL_TO=адрес сотрудника Кванториума
3. Для группы из пяти человек:
   MIN_GROUP_SIZE=5
   TIME_TOLERANCE_MINUTES=60
4. Чтобы ждать восемь человек, установите MIN_GROUP_SIZE=8.
5. После изменения .env перезапустите сервер: Ctrl+C, затем npm start.

ВАЖНО
- Без настройки SMTP заявки будут сохраняться, но письма отправляться не будут.
- Не публикуйте файл .env и не передавайте пароль почты посторонним.
- Это учебный прототип. Для реального запуска в интернете нужны HTTPS, защита от спама,
  резервное копирование, согласование обработки персональных данных и доступ к заявкам
  только уполномоченным сотрудникам.

- Продолжительность занятия — 40 минут, перемена — 10 минут. Время начала выбирается с шагом 50 минут: 10:45, 11:35, 12:25, 13:15, 14:05, 14:55, 15:45, 16:35, 17:25. Последнее занятие заканчивается в 18:05.
